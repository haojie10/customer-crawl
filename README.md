# 外贸采购商精准采集与全景画像系统 (Customer Crawl)

针对外贸大数据平台（TopEase / 特易资讯 / 8号仓）自动化采集与分析工具集。支持广交会买家大批量分卷归档、采购商全景贸易画像深度解析、以及采购决策人（Purchase 职位 + Valid 验证邮箱）的高精度清洗与提取。

---

## 🌟 核心特性

- **多层次深度采集**：
  - **企业列表与基本面**：公司名称、所在国家/地区、企业税号、官方网址、近一年采购频次等。
  - **全景贸易画像**：主营采购产品清单、核心采购 HS 编码、原产国分布、关键供应商图谱。
  - **关键人联系方式**：精准过滤决策人职位（如 `statusList=5` 采购/供应链职位），且仅提取通过验证的高可信度邮箱（`status=2 Valid`）。
- **稳健的反爬机制**：
  - 拟人化动态随机停顿（0.8s ~ 2.5s），降低并发特征，保障账号安全。
  - 严格支持定额分卷爬取（如单批次 50 页 / 500 家企业），避免触发平台单日深度检索风控限制。
- **断点续传与安全落盘**：
  - 独立 JSON 进度追踪（`crawl_progress_*.json`），网络异常或 Token 到期后可秒级无缝断点恢复。
  - 采集过程中按设定间隔自动保存落盘（默认每 5 页保存一次），保证已爬取数据零丢失。
- **高品质 Excel 数据导出**：
  - 自动样式排版（微软雅黑字体、居中/居左对齐、细边框美化、自动列宽适配）。
  - 自动清洗非法 XML/Excel 控制字符，杜绝写入损坏。

## 🛠️ 安装与使用

### 1. 安装环境依赖

推荐使用 Python 3.10 及以上环境：

```bash
pip install -r requirements.txt
```

### 2. 配置认证凭证

从浏览器开发者工具（Network 标签页）获取当前登录的 `authorization` 与 `topease_access_token`：

在对应脚本中配置：
```python
AUTH_TOKEN = "your_access_token_here"
```
或在终端配置环境变量：
```bash
set TOPEASE_TOKEN=your_access_token_here
```

### 3. 运行采集

```bash
python -u crawl_eu_buyers_151_200.py
```

终端将实时输出进度条、累计获取企业数、有效采购决策人数量及耗时统计。
